# Ravenstash CLI 0.16.0

Ravenstash CLI 0.16.0 adds two package-tool commands: `rvs pnpm` and `rvs python -m build`.

## Update

```bash
rvs update --apply
```

On Debian and Ubuntu installations, `sudo apt update && sudo apt upgrade` installs it as well. For a new installation, see the [quickstart](../quickstart.md).

## Changes

- `rvs pnpm` runs pnpm 9 to 12 with temporary access to a Ravenstash npm repository, like `rvs npm`. Installs read from the selected repository, even when a project `.npmrc` or `pnpm-workspace.yaml` names another registry. `publish` (including `pnpm -r publish`), `dist-tag`, `deprecate`, and `unpublish` use its publish address after the same confirmations as `rvs npm`. `rvs` warns when `package.json` pins another pnpm version, which pnpm would download from the selected repository. `rvs art native config pnpm` prints a manual setup.
- `rvs python -m build` runs pypa/build with temporary read access, so build requirements come from the selected repository. Pair it with `rvs twine upload dist/*`. Other Python commands are refused.
- Old-client version checks run outside the project directory, so a `packageManager` pin no longer makes pnpm download another version just to report its own.

See the [command reference](../command-reference.md#package-tool-commands) for details. The [changelog](../../CHANGELOG.md) lists every release.
