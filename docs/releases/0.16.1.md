# Ravenstash CLI 0.16.1

Ravenstash CLI 0.16.1 is a maintenance release. The Linux and macOS installer now retries interrupted downloads, the bundled libraries are updated, and the Nix flake no longer provides a package for Intel Macs. No `rvs` command, option, or output changes.

## Update

```bash
rvs update --apply
```

On Debian and Ubuntu installations, `sudo apt update && sudo apt upgrade` installs it as well. For a new installation, see the [quickstart](../quickstart.md).

## Changes

- The Linux and macOS installer retries a download up to three times when the connection drops or is reset, instead of failing the installation on the first network error. HTTP errors such as a missing release still fail at once.
- Updated the bundled libraries: httpx2 2.16.2, Typer 0.28.0, Click 8.5.1, PyYAML 6.0.4, and packaging 26.4, together with the libraries they depend on.
- macOS 15 is now the oldest supported macOS on Apple Silicon, as it already was on Intel. Existing macOS 14 installations are not blocked.
- The Nix flake no longer provides a package for Intel Macs (`x86_64-darwin`): Nixpkgs 26.05 is the last Nixpkgs release for them, and Nix 2.36 is no longer released for them. On an Intel Mac, use the signed portable archive from `install.sh`. An existing Nix installation on an Intel Mac keeps its current release, because `rvs update --apply` cannot install a newer one there and restores the installed release.

The [changelog](../../CHANGELOG.md) lists every release.
