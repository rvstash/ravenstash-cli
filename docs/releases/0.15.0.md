# Ravenstash CLI 0.15.0

Ravenstash CLI 0.15.0 is the first public release. It installs the `rvs` command and its full-name alias `ravenstash`.

## Install

```bash
curl -fsSL https://ravenstash.com/install.sh | bash
rvs --version
```

On Debian and Ubuntu the installer adds the signed Ravenstash APT repository and installs the `ravenstash-cli` package. On other Linux distributions and on macOS it installs a signed portable archive; on Windows, use `irm https://ravenstash.com/install.ps1 | iex`. A Nix flake is provided as well.

## What it does

- Signs in with your browser, keeps secrets in the operating system keyring or an encrypted vault, and switches between personal and organization accounts.
- Works with private repositories and private mirrors for PyPI, npm, Maven, and OCI content, including container images and Helm charts.
- Runs pip, uv, Twine, npm, Maven, Docker, Helm, and ORAS with short-lived Ravenstash access, so credentials are never saved in project files.
- Manages packages, versions, tags, and OCI content, and uploads package security evidence.

See the [quickstart](../quickstart.md) and the [command reference](../command-reference.md).

## Updates and compatibility

The CLI and the Ravenstash API are pre-1.0. Commands, options, and output can change between 0.x releases; the [changelog](../../CHANGELOG.md) names every change. Stay on the latest release:

```bash
rvs update --apply
```

Every release from 0.15.0 on can find, verify, and install the latest release in the rolling `v0` channel, and the latest release reads the configuration of every release since 0.15.0.

A configuration written by a pre-release version of `rvs` is not migrated. `rvs` leaves it untouched and asks you to reset your profiles and sign in again.
