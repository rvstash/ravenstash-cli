# Ravenstash CLI 0.15.1

Ravenstash CLI 0.15.1 is a maintenance release. It updates the libraries bundled with `rvs` and changes no command, option, or output.

## Update

```bash
rvs update --apply
```

On Debian and Ubuntu installations, `sudo apt update && sudo apt upgrade` installs it as well. For a new installation, see the [quickstart](../quickstart.md).

## Changes

- Updated the bundled libraries: Click 8.5.0, Typer 0.27.3, httpx2 2.13.1, cryptography 50.0.2, and idna 3.20.

The [changelog](../../CHANGELOG.md) lists every release.
