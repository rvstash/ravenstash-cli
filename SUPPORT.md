# Support

- For usage questions and ideas, start a [GitHub Discussion](https://github.com/rvstash/ravenstash-cli/discussions).
- For a reproducible CLI bug or feature proposal, use the repository's [issue forms](https://github.com/rvstash/ravenstash-cli/issues/new/choose).
- For account, billing, abuse, or other private matters, email [support@ravenstash.com](mailto:support@ravenstash.com). Do not put credentials or customer data in a public issue.
- For security vulnerabilities, use the private process in [SECURITY.md](SECURITY.md).

Include the `rvs --version` output, operating system and architecture, the command you ran, and a minimal sanitized reproduction. Remove access tokens, repository credentials, package contents, and personal information from logs.
